Ecuación base del modelo probit

ηᵢₖ = αₖ + gᵢₖ + hᵢₖ

P(yᵢₖ = 1) = Φ(ηᵢₖ)

αₖ · tendencia globalNivel base del rasgo antes de añadir geografía o genealogía.

gᵢₖ · efecto espacialDesviación relacionada con las ubicaciones de las lenguas.

hᵢₖ · efecto filogenéticoDesviación relacionada con las ramas compartidas del árbol.

Φ transforma la puntuación probit η en una probabilidad entre 0 y 1. Las celdas faltantes no se tratan como ceros: se predicen después del ajuste.

Distribución posterior de la probabilidad

Cómo interpretar esta distribución

Cada muestra posterior produce un valor posible para la probabilidad de la clase positiva. El ancho del histograma resume incertidumbre sobre esa probabilidad; no representa una distribución de hablantes ni de lenguas.

La probabilidad predictiva es el promedio de las muestras. La probabilidad de la clase negativa es uno menos ese promedio.

Rendimiento en datos reservados

Cada rasgo se evalúa en sus propias lenguas de test. Las barras muestran métricas donde valores mayores son mejores; las pérdidas se muestran por separado.

Calidad de las probabilidades

Cobertura y partición de datos

El split se estratifica por clase y agrupa por glottocódigo. Se realiza por separado para cada rasgo; una lengua puede ser train para uno y test para otro.

«Fuera de alcance» son categorías excluidas de la respuesta binaria. «Excluidas» son lenguas que no cumplieron requisitos de alineación, coordenadas o datos necesarios.

Cómo leer las métricas

  • Exactitud y exactitud balanceada: proporción de aciertos; la balanceada promedia el acierto de cada clase.
  • AUC: capacidad de ordenar positivos por encima de negativos a través de umbrales.
  • Precisión, recall y F1: resumen de detección de la clase positiva usando umbral 0,5.
  • MCC: correlación entre clases reales y predichas; 1 es perfecto, 0 equivale a ausencia de asociación y -1 a desacuerdo total.
  • Brier y log-loss: penalizan probabilidades mal calibradas; valores menores son mejores.
