# Datos GBI incluidos

Estos ficheros se extrajeron de la release GBI/TLI v1.0.0 publicada con el artículo de Graff et al. (2025). Se usa la tabla estadísticamente curada de Grambank y sus metadata CLDF:

- `statisticalGBI.csv`: matriz de lenguas por rasgos;
- `languages.csv`: nombres, glottocódigos, coordenadas y metadata de lenguas;
- `parameters.csv`: definiciones y decisiones de curación de rasgos;
- `codes.csv` y `modifications.csv`: códigos y registro de modificaciones.

**Cita:** Graff, A., Chousou-Polydouri, N., Inman, D., Skirgård, H., Lischka, M., Zakharko, T., Barbieri, C. & Bickel, B. (2025). *Curating global datasets of structural linguistic features for independence*. Scientific Data, 12, 106. [https://doi.org/10.1038/s41597-024-04319-4](https://doi.org/10.1038/s41597-024-04319-4).

**Datos y scripts:** [annagraff/crossling-curated](https://github.com/annagraff/crossling-curated), [release v1.0.0 en Zenodo](https://doi.org/10.5281/zenodo.14606326).
